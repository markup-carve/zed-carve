# zed-carve

Carve support for Zed with Tree-sitter highlighting and managed `carve-lsp` integration. Extension version 0.1.8 pins its grammar revision in `extension.toml`. See the [Carve documentation](https://markup-carve.github.io/carve/) for the markup language.

## Features

- Highlighting and fenced code injections.
- Diagnostics, completion, navigation, and formatting.

## Install

Install [Carve from the Zed extension registry](https://zed.dev/extensions/carve).

## Usage

Open a `.crv` file to use Carve highlighting and language server features.
